Privacy policy

Test Mail Reader uses the Gmail API with read-only access (gmail.readonly) to a dedicated test mailbox owned by the developer, only to run automated QA tests.

  • Data accessed: content of test emails in that mailbox.
  • Data is used only during test execution and is not stored, sold or shared with third parties.
  • No data from other Google accounts is accessed.
  • Access can be revoked at any time from the Google Account settings of the test mailbox.
